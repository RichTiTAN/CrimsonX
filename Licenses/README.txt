CrimsonX - third-party licence texts

This folder holds the licence text of every third-party component that CrimsonX
ships. THIRD-PARTY-NOTICES.txt at the application root maps each component to
its file here and lists its upstream project.

  Xray-core-LICENSE.txt                 Xray-core
  sing-box-LICENSE.txt                  sing-box
  amnezia-box-LICENSE.txt               amnezia-box (AmneziaWG support)
  crimsonipsec-THIRD-PARTY-NOTICES.txt  crimsonipsec (IKEv2 engine)
  Avalonia-MIT.txt                      Avalonia UI
  Newtonsoft.Json-MIT.txt               Newtonsoft.Json
  dotnet-runtime-MIT.txt                .NET runtime
  Aether\                               Aether, psiphon-tunnel-core and lyrebird

The texts are shipped unmodified. Do not edit them.
